# MinIO и Nginx (Прокси)

Этот раздел описывает **пошаговую настройку** объектного хранилища MinIO и прокси-сервера Nginx для доступа к статическому контенту.

> ⚠️ **Предварительное условие:** инфраструктура создана в Terraform, NFS настроен (Задание 1). Если нет — вернитесь к основному README.

## 📂 Что уже есть в репозитории

Вам **не нужно создавать файлы вручную**. Все роли, плейбуки и шаблоны уже лежат в папке `ansible/`:

```text
ansible/
├── playbooks/
│   ├── minio.yml           # Плейбук для MinIO
│   └── nginx.yml           # Плейбук для Nginx
└── roles/
    ├── minio/
    │   ├── defaults/main.yml  # Переменные (пути, порты, имена)
    │   ├── tasks/main.yml     # Задачи (Docker, mc, бакеты)
    │   └── vars/vault.yml     # Секреты (создаете вы)
    └── nginx_proxy/
        ├── defaults/main.yml  # Переменные (IP MinIO, порт)
        ├── tasks/main.yml     # Установка Nginx, копирование конфига
        ├── handlers/main.yml  # Перезапуск Nginx
        └── templates/nginx.conf.j2 # Шаблон конфига Nginx
```

**Что нужно сделать вам:**
1. Создать `inventory.ini` (из шаблона `inventory.example.ini`).
2. Создать `vault.yml` (через `ansible-vault create`).
3. Запустить плейбуки.

---

## 🔐 Шаг 1. Настройка секретов (Ansible Vault)

MinIO требует паролей. Мы используем Ansible Vault, чтобы не хранить их в открытом виде.

1. Создайте Vault-файл:
   ```bash
   ansible-vault create roles/minio/vars/vault.yml
   ```
   *(Придумайте пароль шифрования для Vault и запишите его)*.

2. Внутри созданного файла напишите:
   ```yaml
   vault_minio_root_password: "придумай свой пароль"
   vault_minio_client_password: "придумай свой пароль"
   ```
   *(Сохраните изменения и выберитесь из редактора: `Esc`, затем `:wq`, `Enter`)*.

3. Проверьте, что файл успешно зашифрован:
   ```bash
   ansible-vault view roles/minio/vars/vault.yml --ask-vault-pass
   ```

---

## 🚀 Шаг 2. Настройка MinIO (Сервер)

1. Запустите плейбук установки MinIO:
   ```bash
   ansible-playbook -i inventory.ini playbooks/minio.yml --ask-vault-pass
   ```
   *(Введите установленный ранее пароль от Vault)*.

2. Подключитесь по SSH и проверьте, что Docker-контейнер запущен:
   ```bash
   ssh s6ade@<IP_СЕРВЕРА>
   sudo docker ps
   ```
   *(В списке должен присутствовать контейнер `minio` со статусом `Up`)*.

3. Проверьте создание бакета `suito` и наличие файла `index.html`:
   ```bash
   mc ls local/suito
   ```
   *(В выводе должен отобразиться файл `index.html`)*.

4. Проверьте, что политика бакета является публичной:
   ```bash
   mc anonymous get local/suito
   ```
   *(Должен вернуться статус `download`)*.

5. Проверьте доступ к веб-консоли:
   * Откройте в браузере: `http://<IP_СЕРВЕРА>:9001`
   * Логин: `minio_admin`
   * Пароль: `SuperSecret2309`
   *(Убедитесь, что внутри отображается бакет `suito` и файл `index.html`)*.

---

## 🌐 Шаг 3. Настройка Nginx (Клиент)

1. Запустите плейбук для настройки Nginx:
   ```bash
   ansible-playbook -i inventory.ini playbooks/nginx.yml
   ```

2. Подключитесь по SSH и убедитесь, что служба Nginx активна:
   ```bash
   ssh s6ade@<IP_КЛИЕНТА>
   sudo systemctl status nginx
   ```
   *(Статус должен быть `active (running)`)*.

3. Проверьте сгенерированный конфигурационный файл:
   ```bash
   cat /etc/nginx/sites-available/default
   ```
   *(В директиве `proxy_pass` должен быть указан прямой путь к `index.html` внутри MinIO)*.

---

## 📋 Шаг 4. Проверка (Финальный тест)

1. Откройте веб-браузер на своем рабочем компьютере.
2. Введите IP-адрес клиента: `http://<IP_КЛИЕНТА>` (например, `http://153.51.165.13`).

**Ожидаемый результат:** На экране должна отобразиться страница с текстом **«Hello World!»**. Если страница успешно открылась — задание полностью выполнено.

## ⚠️ Известные проблемы и их решение

* **Ошибка 400 Bad Request при проксировании MinIO**
  * **Причина:** MinIO (Silo) строго валидирует заголовок `Host` и отклоняет прокси-запросы, направленные на корень бакета.
  * **Решение:** В шаблоне `nginx.conf.j2` настраивайте `proxy_pass` на конкретный файл (`/suito/index.html`), а не на корень. Также убедитесь, что бакет публичный с помощью команды `mc anonymous set download local/suito`.

* **Ошибка `vault_minio_root_password is undefined`**
  * **Причина:** Ansible не загружает или не находит файл с секретами Vault.
  * **Решение:** Проверьте наличие аргумента `--ask-vault-pass` при запуске, а также убедитесь, что в файле `playbooks/minio.yml` подключена секция:
    ```yaml
    vars_files:
      - roles/minio/vars/vault.yml
    ```

* **Ошибка `Image minio/minio:latest not found`**
  * **Причина:** Официальные образы MinIO были удалены или перемещены из Docker Hub.
  * **Решение:** Внутри Ansible-роли `minio` прописан и используется альтернативный поддерживаемый форк-образ `pgsty/silo:latest`.

* **Ошибка `Bucket name contains invalid characters`**
  * **Причина:** Имя создаваемого бакета содержит запрещенные символы (например, нижние подчеркивания `_`).
  * **Решение:** Используйте для именования бакетов только строчные латинские буквы, цифры и дефисы (например, `user-bucket`).
